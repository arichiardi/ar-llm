# @ar-llm/pi-notify

[![MIT](https://img.shields.io/badge/license-MIT-green.svg)](./LICENSE)

Pi extension that sends a native terminal notification (OSC 777 / OSC 99 / Windows toast) when the agent finishes and is waiting for input.

## Install

```bash
pi install 'npm:@ar-llm/pi-notify'
```

Or try without installing:

```bash
pi -e 'npm:@ar-llm/pi-notify'
```
